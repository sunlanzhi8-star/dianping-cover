◎ Live 照片怎么用
只做封面：直接选 Live 照片即可。
网页会使用它的静态封面，加 IP 后保存 PNG / JPG，不需要先转成视频。

想保留原来的 Live 动态？

当前网页暂不支持从 iPhone 相册直接读取并保存完整 Live Photo。选进来的静态画面不包含原始动作，添加到主屏幕也不会改变这一限制。

如果接受导出普通动态视频

在“照片”打开实况图 → 右上角“…” → “存储为视频”，再把视频选进本页。加好 IP 后可以导出动态视频，或保存当前帧。

使用与草稿说明

两个账号各保留一份草稿，切换账号不会覆盖另一个账号的照片、文字和贴纸。照片处理在设备上完成，网站不会上传你的相册内容。

草稿仅保存在当前网址、当前浏览器；不会在苹果和安卓之间同步。无痕模式、清理浏览器数据或存储空间不足可能影响保存。

放到桌面：iPhone 用 Safari 的分享菜单“添加到主屏幕”；安卓可用 Chrome 菜单“添加到主屏幕”。首次打开网页仍需网络；下载的单文件 HTML 可独立保留。
